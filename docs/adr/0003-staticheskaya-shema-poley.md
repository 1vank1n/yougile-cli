# 0003. Статическая схема полей и короткое замыкание `--json` до клиента

## Контекст

`--json` без значения печатает перечень доступных полей, но собирал его из полученных строк: без токена и на пустой выдаче перечня не было. Issue #3 предлагала два пути — сделать перечень доступным или описать ограничение в документации.

## Решение

Новый модуль `src/yougile_cli/fields.py` хранит `RESOURCE_FIELDS` — поля по ресурсам API v2 и по наборам, которые CLI составляет сам. `output.fields_error()` принимает имя ресурса и печатает объединение статической схемы с полями реального ответа. Проверка голого `--json` стоит до `app_ctx.client()`; там, где статической схемы нет, замыкание не срабатывает и команда идёт в сеть, как раньше.

## Почему

Документирование ограничения (вторая опция issue) отвергнуто: сама issue называет его не исправлением — сценарий «заготовить вызов до логина» остаётся невыполнимым.

Замыкание ставится до создания клиента, а не после: пользователь просит имена полей, а не данные, и проверка токена с сетевым запросом на этом пути только мешают — именно они и были причиной issue.

Замыкание не безусловное: у команд без статической схемы безусловное замыкание отняло бы перечень, который у них уже работал по ответу. Issue просит расширить доступность перечня, а не сузить.

Объединение схемы с полями ответа, а не только схема: сервер возвращает поля, которых в схеме нет, и терять их нельзя.

Отдельный модуль, а не константа в `output.py`: схема — данные о ресурсах API, а `output.py` про формат вывода; смешение сделало бы `output` местом, куда дописывают знания об API.

Источник имён — только флаги `create`/`edit`, колонки таблиц и фикстуры `tests/`: описания эндпоинтов в репозитории нет, а выдуманное поле в перечне хуже отсутствующего.

## Последствия

Схема — ручная копия знаний об API, и она стареет молча: новое поле сервера попадёт в перечень только там, где ответ пришёл, а на пустой выдаче о нём не узнают. Каждый новый ресурс требует правки `fields.py`, иначе его `--json` тихо откатывается к сетевому поведению. Появилась публичная граница `fields`, которую придётся поддерживать.
